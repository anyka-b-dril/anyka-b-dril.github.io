    <h1>Self-Assessment</h1>
</div>
<div align="left">
    <p>SNHU’s computer science program transformed my technical curiosity into a solid theoretical foundation. I focused on practical, project-based software engineering, algorithmic problem-solving, and integrating modern technologies. Throughout the program, I built a portfolio of industry-standard applications that solve complex engineering problems, demonstrating my growth as a software engineer. Guided by a strong ethical framework, this education sharpened my programming skills and strengthened my practical application—ultimately preparing me to be a competitive, adaptable engineer. </p>
    <p>Beginning with the Programming Languages course, I gained hands-on coding experience in C++ and built a simple investment calculator. This project was the first C++ application; it utilized a header and corresponding source files to keep the codebase organized. In Introduction to Structured Database Environments, I built a strong foundation in relational database design and managed data through queries. DSA Analysis and Design gave me in-depth technical knowledge of data structures, algorithms, and the importance of efficient data management. Several intermediate courses strengthened my knowledge of industry-standard frameworks and processes, helping me collaborate in a team environment and communicate effectively with stakeholders. In the Software Development Lifecycle course, I interviewed the client and users to understand their motivations, desired features, and application context, enabling me to create effective user stories and goals to share with a development team. In System Analysis and Design, I created extensive UML diagrams, data flow charts, and design documents, which strengthened my system design, communication, and documentation skills. Additionally, I used testing frameworks and iterative development tools such as JUnit and Maven in Software Testing and Automation and Software Security. I implemented SHA-256 hashing algorithms, self-signed certificates, NIST and FIPS security standards, and the OWASP Dependency-Check tool to build multi-layered security.</p>
    <p>These experiences elevated my work in later courses, such as Mobile Architect and Programming, Client/Server Development, and Full Stack Development. In Mobile Architect and Programming, I utilized Android Studio to build a multi-screen, database-driven application. This project focused on reducing user cognitive load, which reinforced the importance of user flow diagrams and wireframes to map each step of the user interface. It also challenged my ability to learn new tools, design a seamless user experience, and implement unfamiliar SQL database drivers to populate the application. Client/Server Development pushed me to use my database management skills to connect a back-end MongoDB database to an interactive front-end dashboard that visually organized data and communicated it effectively to users. Lastly, these skills prepared me to build a full-stack Travlr Getaways application using Express, HTML, JavaScript, MongoDB, and a single-page application to manage and view trips for clients and administrators. Ultimately, I developed familiarity with MEAN stack application architecture, RESTful API engineering, JWT implementation, Cross-Origin Resource Sharing (CORS), and State management with observables and RxJS.</p>
    <p>To demonstrate these skills, I assembled three showcase artifacts in this portfolio. Together, they reflect my practical experience in building scalable software, optimizing algorithmic efficiency, and implementing multiple layers of security—offering a concrete representation of the value and technical expertise I bring to an engineering team. First, to showcase my software design and engineering skills, I refactored my existing appointment manager architecture from Software Testing and Automation to use an industry-standard model-view-controller framework. Next, I upgraded the course catalog artifact from DSA Analysis and Design. Instead of using the convenient vector data structure with O(n) search time, I upgraded the application to use an unordered map, achieving average O(1) constant-time data lookups. Lastly, I continued expanding the appointment manager's data structure and added a MongoDB database, complete with integration testing.</p>
